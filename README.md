# 🌟 Smart Focus Flow (스마트 포커스 플로우)

> **뽀모도로 몰입 타이머와 지능형 할 일 관리가 결합된 고성능 순수 바닐라 웹 애플리케이션**  
> 외부 라이브러리나 무거운 프레임워크 없이, 순수 HTML5, CSS3, 바닐라 JavaScript만으로 구현된 가볍고 강력한 생산성 도구입니다.

---

## 🖥️ 화면 미리보기 및 레이아웃 특징

- **데스크톱 환경 (960px 이상)**:
  - **좌측 패널 (Sticky Sidebar, 390px)**: 스크롤을 내려도 뽀모도로 타이머와 진행률 대시보드, 카테고리 필터가 시야에 고정되어 지속적인 몰입감을 제공합니다.
  - **우측 패널 (Main Panel)**: 시원한 작업 공간에서 실시간 검색, 키워드 자동 분류 입력, 드래그 앤 드롭 정렬을 자유롭게 조작할 수 있습니다.
- **모바일/태블릿 환경**:
  - 화면 크기에 따라 직관적인 단일 컬럼 스택으로 자동 전환되는 반응형 그리드 웹 디자인을 지원합니다.

## ✨ 핵심 기능 둘러보기

### 1. ⏱️ 25분 뽀모도로 타이머
- 표준 뽀모도로 기법(25분 집중) 기반 카운트다운 타이머.
- **Web Audio API 오실레이터 화음 비프음**: 외부 오디오 파일 다운로드 없이 브라우저 자체 음원 합성으로 00:00 도달 시 부드러운 알림 사운드를 재생합니다.
- 브라우저 탭 타이틀(`(24:59) Smart Focus Flow`)과 실시간 연동되어 다른 탭을 볼 때도 남은 시간을 확인할 수 있습니다.

### 2. 🤖 키워드 기반 실시간 자동 카테고리 분류
- 할 일을 입력하는 순간 텍스트를 실시간으로 분석하여 적합한 카테고리를 자동으로 선택해 줍니다.
  - **💼 업무 (`work`)**: 회의, 미팅, 보고, 메일, 프로젝트, 기획, 개발, 코딩, 배포, 결재, 마감 등
  - **🌱 개인 (`personal`)**: 장보기, 마트, 병원, 운동, 헬스, 청소, 빨래, 약속, 여행, 요리, 쇼핑 등
  - **📚 공부 (`study`)**: 공부, 복습, 예습, 시험, 강의, 과제, 독서, 책, 자격증, 알고리즘 등
- 자동 감지 시 셀렉트 박스에 부드러운 스케일 펄스 애니메이션(`.auto-selected-pulse`)이 작동합니다.

### 3. 📊 진행률 통계 대시보드
- **전체 진행률**: `"N/M 완료 (XX%)"` 형식의 텍스트와 그라디언트 프로그레스 바로 달성률을 한눈에 파악합니다.
- **카테고리별 미니 프로그레스 바**: 업무(블루), 개인(그린), 공부(퍼플) 카테고리별 개별 진행률을 실시간 연동합니다.
- **활동 통계 배지**: 오늘 자정 이후 추가된 작업 수(`📅`)와 완주한 뽀모도로 집중 세션 횟수(`⏱️`)를 누적 기록합니다.

### 4. ✏️ 더블클릭 인라인 수정
- 목록의 할 일 텍스트를 **더블클릭**하면 인라인 편집 모드로 전환됩니다.
- 텍스트 수정뿐만 아니라 카테고리 드롭다운도 함께 변경할 수 있으며, <kbd>Enter</kbd>(저장), <kbd>ESC</kbd>(취소) 단축키를 지원합니다.

### 5. 🌓 모던 다크 모드
- 우측 상단 토글 버튼을 통해 다크 모드와 라이트 모드를 자유롭게 전환할 수 있습니다.
- 세련된 다크 테마 팔레트(배경 `#1A1A1A`, 카드 `#2D2D2D`, 본문 `#E0E0E0`)와 `0.3s` 부드러운 전환 효과가 적용됩니다.
- `localStorage`에 저장되어 재접속 시에도 유지되며, 초기 접속 시 사용자의 OS 테마를 자동 감지합니다.

### 6. 🔍 실시간 검색 & 다중 정렬 & 수동 드래그 앤 드롭
- **실시간 디바운스 검색**: 120ms 디바운스가 적용된 초고속 텍스트 검색 및 원클릭 초기화(✕).
- **5가지 정렬 옵션**:
  - ⬇️ 최신 등록순 / ⬆️ 과거 등록순 / 🏷️ 카테고리순 / ⏳ 미완료 우선순 / ✋ 사용자 수동순
- **HTML5 Drag and Drop**: 드래그 핸들(`⋮⋮`)을 잡고 원하는 위치로 끌어다 놓으면 순서가 즉시 재배치되며 수동 정렬 순서가 보존됩니다.

### 7. 📦 JSON 데이터 백업 & 안전 복원 (Export/Import)
- **내보내기 (Export)**: 클릭 한 번으로 모든 할 일, 완료 세션 수, 테마, 정렬 상태가 담긴 JSON 백업 파일 다운로드.
- **복원 (Import)**: 백업 파일을 업로드하여 데이터를 원클릭으로 복원.
- **3버튼 안전 모달**: 기존 데이터가 있을 경우 덮어쓰기 전에 **[백업 후 가져오기]**, **[바로 가져오기]**, **[취소]** 중 선택할 수 있어 데이터 유실을 방지합니다.

### 8. ⚡ 100개 이상 대용량 고속 렌더링 최적화
- `DocumentFragment`를 활용하여 100개 이상의 아이템도 단 1회의 브라우저 리플로우(Reflow)로 렌더링하여 프레임 드랍 없는 부드러운 성능을 제공합니다.

## ⌨️ 키보드 단축키 가이드

| 단축키 | 동작 설명 |
| :--- | :--- |
| <kbd>Alt</kbd> + <kbd>N</kbd> | 새 작업 입력창으로 즉시 포커스 이동 |
| <kbd>Alt</kbd> + <kbd>1</kbd> | 카테고리 필터: **전체** 보기 |
| <kbd>Alt</kbd> + <kbd>2</kbd> | 카테고리 필터: **💼 업무** 보기 |
| <kbd>Alt</kbd> + <kbd>3</kbd> | 카테고리 필터: **🌱 개인** 보기 |
| <kbd>Alt</kbd> + <kbd>4</kbd> | 카테고리 필터: **📚 공부** 보기 |
| <kbd>ESC</kbd> | 열려 있는 확인 모달 닫기 또는 인라인 수정 취소 |
| <kbd>Enter</kbd> | 새 작업 등록 / 인라인 수정 저장 (한글 IME 중복 방지) |

## 📁 파일 구조

```text
smart-focus-flow/
├── index.html        # 반응형 2단 시맨틱 마크업 (좌측 사이드바 + 우측 메인 영역)
├── style.css         # 모던 카드 디자인, 다크 모드 테마, 애니메이션 및 2단 반응형 그리드
├── script.js         # 뽀모도로 타이머, 자동 분류, 정렬, 드래그앤드롭, 로컬스토리지 연동
├── GEMINI.md         # 프로젝트 지침, 진행 상황 체크리스트 및 Mermaid 아키텍처 다이어그램
├── README.md         # 사용자 종합 가이드 문서 (본 파일)
└── backup/           # 이전 단일 컬럼 버전 소스 파일 분리 보관소
    ├── index.html
    ├── style.css
    └── script.js
```

## 🚀 실행 방법

별도의 Node.js 설치나 빌드 과정이 필요하지 않습니다.

1. 본 프로젝트 폴더에서 [`index.html`](file:///c:/바이브코딩/실습과제/index.html) 파일을 웹 브라우저(Chrome, Edge, Safari 등)로 더블클릭하여 바로 열면 즉시 실행됩니다.
2. 모든 데이터는 브라우저의 `localStorage`에 안전하게 저장되므로 인터넷 연결이 없어도 오프라인에서 완전하게 동작합니다.
